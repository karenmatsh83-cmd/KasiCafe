Kasi Café – HTML Multi-Page Website

About the Project

Kasi Café is a basic multi-page website created as part of an HTML Web Development practical task.

The website provides information about Kasi Café, its products and prices, business hours and contact information.

Website Pages

The website contains four HTML pages:

1. Home Page – "index.html"
   
   - Welcome message
   - Café image
   - Introduction to Kasi Café
   - Navigation links

2. About Us – "about.html"
   
   - Café background
   - Mission and vision
   - Opening hours
   - Café image

3. Products – "products.html"
   
   - List of products
   - Product table
   - Product names, categories, descriptions, sizes and prices
   - Food images

4. Contact Us – "contact.html"
   
   - Café address
   - Telephone number
   - Email address
   - Business hours
   - Contact options
   - Links to the other pages

Technologies Used

- HTML5

No CSS or JavaScript was used because the practical task requires HTML only.

Purpose

The purpose of this website is to demonstrate the ability to create and connect multiple HTML pages using headings, paragraphs, lists, tables, images and hyperlinks.
